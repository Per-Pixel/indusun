## Auth Images

This folder contains images used in the authentication pages.

Please add the following images from your Figma design:

1. `login-bg.jpg` - The modern building/architecture image for the login page background
2. `signup-bg.jpg` - The modern building/architecture image for the signup page background
3. `house-icon.svg` - The house/building icon used in the welcome heading

You can export these directly from your Figma design.
